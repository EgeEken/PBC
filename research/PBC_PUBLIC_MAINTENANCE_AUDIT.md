## Access notes

GitHub PBC/profile content was fetched through the GitHub connector; portfolio source was fetched from `EgeEken/egeeken.github.io`. The live HF API metadata, homepage, one bundled sample roundtrip and limited logs were inspected. No admin mutation was invoked. GitHub Pages URLs were not rendered, and no full HF UI/mobile or desktop executable test occurred. Both CVs were text-extracted and visually rendered; no CV or public correction occurred. This is a scoped maintenance audit, not a full security review.
