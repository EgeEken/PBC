# Pass 3 frozen initial plan

Only research_pass3 is writable by these experiments. Prior research, production runtime/defaults, model, datasets and user work are controls. No remote request, commit, push, deployment, restart or training.

Reuse the actual Pass 2 persistent benchmark worker and stream parser by importing them read-only and redirecting only their output globals into Pass 3. The local worker extension adds experiment counters to the same independently decoded metrics. Keep release and current root separate; retain model/input/source hashes, exact config, actual patches/dimensions, complete/raw bytes and full encode/decode walls. One numerical thread, worker CPU affinity 0, warmed paths, rotated order, three primary timing repeats. No concurrent CPU benchmarks.

A: check dtype/bit alignment, truncation and unusual RGB/RGBA inputs; screen baseline/grid/skip/both on the same six Pass 2 main images, all four presets, three repeats. Freeze a full 25-image/four-preset four-variant run after exactness. Harden only the experimental grid helper's argument/payload checks; production remains unchanged. Explicitly inspect result.mse=None callers and allocation/import costs before claiming deployment readiness.

B1/B2: frozen release/root Q250/HQ250 and current-root 500k/35 on cat, Monet, flower, cathedral, googlewiki and stockpoint. Log all iterative patch costs, exact clipped working SSE changes and signed quantized grids. Sample first/thirds/last/largest-raw-cost patches (at most five per trajectory) for original, coarser grid, one lower precision, and a finer grid diagnostic. Sample RGB and marginal final-file effects at those positions; never call raw cost additive compressed ownership. Shortlist at most two local >=98% gain / <=75% raw-bit alternatives per stream for one full fixed-suffix file check. Only consider a selector if useful alternatives exist.

If warranted, B3a is one forward replay with original geometry/channel/order/count held fixed, fitting candidate patches to the evolving replay canvas. A complete original encode is included before this replay so all diagnostic overhead is charged; no backward refit, pruning or repeated full-decode loop. Reference representation versus two cheap alternatives only. Proposed utility is gain - t*(original_gain/original_bits)*candidate_bits, with original positive-gain stop preserved and strict original tie preference. Choose three bracketed t values from B2 evidence, no additional boxes/model calls. B3b, only after a useful B3a signal, uses the same representation rule immediately after the ordinary geometry/model action inside the sequential encoder. Geometry/state may then evolve naturally. Keep 250k and 500k controls unchanged and promote at most two frozen configurations. Holdout only after fixed decisions.

This differs from historical 18-action near-policy searches: at most three representations, original/coarser/lower-precision only, no broader geometry beam, normalized bounded rate penalty, explicit fixed-geometry control and actual-stream Q–HQ curves. No new palette/stream syntax or entropy ranking.

C: at most two exact reuse strategies after B's diagnostic/selection screen. First share the full-channel absolute error array already computed for channel scores with search. Second maintain that map and its exact integer total only over accepted patch rectangles. In both cases rebuild integrals with the original NumPy operation/order; do not maintain/update 2D integrals or reproduce rejected integral fusion. Validate full intermediate maps, totals, selected trajectories and bytes before uninstrumented timings; promote at most one. Treat memory/bookkeeping as part of the experiment.

No content-routing classifier unless fixed-resolution RD results clearly justify it. No large derivative corpus; retain only measurements, essential grid diagnostics and first-repeat candidate files needed for verification.
