# PBC V4 Pass 42 — First architecture prototype

This directory contains the isolated PBC4 V4-A architecture experiment. Read `../research/PBC_V4_GOALS.md` for project goals. `ARCHITECTURE.md` describes the stream and decoder; `EXPERIMENT_DESIGN.md` freezes the first bounded matrix. Production PBC, PBC3 models, release files, GUI and HF Space are not modified.

The initial test focuses on a compact palette initialization plus mutually exclusive protected-SKIP, local procedural and full-resolution DCT region modes with one shared LZMA stream. Validation images remain reserved.
