# Canonical selection

Use the downloadable GitHub V3.1 release ZIP as the **presumptive compatibility reference**, and its embedded Python implementation as the research source-level reference. It is the artifact actually offered to desktop users, and a fresh Coast Compression encode from its embedded Python source reproduced the Pass 44 complete file hash, decoded RGB hash, byte count, and independent MSE. The public release ZIP itself is SHA-verified against the release API.

This is not yet a fully established cross-product canonical implementation: the bundled `PBC.exe` and the user’s installed desktop app were not run, and the HF-uploaded source/stream for the reported incident is unavailable. The HF/research implementation is strongly aligned with the selected source reference (same model, configs, seven source hashes as frozen research); release Python matches all 12 Coast/Cat/Googlewiki frozen research outputs, and eight Pass 26 archived streams match across Cat, Flower, Googlewiki and Mario64. The screenshot discrepancy remains unexplained.

Do not replace deployed HF code or rewrite past measurements on this evidence. Keep the canonical machine-readable manifest marked `provisional` until those compatibility checks are complete.
