# PBC V4 Pass 46

Bounded feasibility study of source-resolution vector-like residual strokes at V3.1 Compression rates, with perceptual baselines and near-rate AVIF brackets. The canonical codec and all previous research remain unchanged.

See `PASS46_RESULTS.md` for conclusions, `PERCEPTUAL_BASELINE.md` for the completed-file comparisons, and `FEASIBILITY_RESULTS.md` / `STRUCTURAL_REPRESENTATION.md` for the local mode screen. `PASS46_SUMMARY.json` indexes the measurements. Generated streams, decoded images, and visuals belong in ignored `outputs/`.

The raw runs are reproducible with `scripts/run_baseline.py`, `scripts/run_feasibility.py`, `scripts/render_feasibility_visuals.py`, and the AVIF bracket scripts, using the pinned release Python under `research_pass45/outputs/published_release_python/`.
