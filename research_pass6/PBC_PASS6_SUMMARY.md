# Pass 6

Runtime integration succeeded and is deployed on the existing HF Space. NumPy grid I/O is called directly; per-encode search state replaces source rewriting/global hooks. Public MSE, presets, model, stream v0 and version remain unchanged.

Local acceptance: all 100 saved main/holdout/preset files and pixels match, plus 20 native/downsample/RGB/RGBA/init-only/heuristic/warmup cases, bidirectional v0 decode, grid alignment/width/integer checks, malformed cases, exact proposal/RNG tests and overlapping calls. The actual public Balanced RGBA response matches the predeployment file, preview and MSE; existing v0 decode also matches.

HF used a six-call initial smoke and 54 timed calls on three images at Quality/HQ, three interleaved repeats, isolated unchanged/integrated workers on one CPU. Mean case-median encode/decode: baseline 0.837813/0.205201 s; integrated with MSE 0.690236/0.106760 s (−17.61%/−47.97%); metric-free 0.602111/0.098735 s (−28.13%/−51.88%). All six public-compatible case medians improved; all same-runtime bytes, pixels, patch trajectories, MSE and bpp match. Repeat variation and source/process provenance are retained. This small set differs from Pass 5, so its percentages are not a new estimate of the old eight-image aggregate.

Decoder-aware refinement was tested independently with fixed feedback 0.5, unchanged palette/geometry/model and no allocator. Six main images × Quality/HQ × three modes × three repeats produced 108 measured calls. B-init changed 32,230 indices across 36 accepted corrections; B-iter changed 9,127 across 27. All accepted local clipped SSE gains and normal decoder reconstructions were verified.

The local gains did not transfer consistently. Equal-case mean RGB MSE changed 220.059462→219.867921 for B-init (−0.087%) and →219.714491 for B-iter (−0.157%). Mean bpp changed 0.928821→0.911521/0.921209. These are fixed-preset aggregates, not matched-rate frontier claims. Mean encode changed +10.75%/+0.71%; decode +1.88%/+1.38%. Initialization's per-case relative-MSE average is −2.35%, a different weighting driven by a few improvements; it does not replace the near-neutral RGB aggregate.

Neither variant passed promotion. No 500k/35, full-main, holdout, combined variant, additional strength or further correction loop was run. Nothing from refinement is deployed on HF. Eiffel HQ's initialization point is useful individually (about −19.67% MSE/−6.29% bpp), but Mario Quality regresses 3.30% MSE and googlewiki regresses at both presets. Cat HQ initialization spends about 10.05% more rate for 0.30% lower MSE. Iterative flower HQ improves 10.97% MSE at 28.27% more rate. Initialization also changes cat/flower Quality stop trajectories from 20/16 to 53 total patches, adding roughly 38%/42% encode time. These are not universal RD improvements.

The four-axis release goal remains unmet: runtime improves while quality/rate are unchanged for the exact integration. Grid feedback does not demonstrate meaningful consistent matched-rate quality gains against the optimized control, and was not qualified for an immutable-release confirmation. No joint quality/rate/encode/decode dominance or PBC 3.1 release is claimed. Compression and Balanced defaults are preserved; the RD experiment is restricted to Q/HQ and makes no low-bitrate benefit claim.

Recommended next step: a bounded stop-policy audit, evaluating one existing ranked alternative only when the learned first proposal would stop. This tests a distinct source of wasted opportunities without training or coefficient feedback. Require actual near-rate controls and a strict CPU budget before extending to independent images. No second strength or larger optimizer for the failed feedback is recommended.
